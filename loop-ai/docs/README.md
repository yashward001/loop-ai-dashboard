# LOOP.AI - AI-Powered Email Productivity Dashboard

An AI-powered dashboard that automatically categorizes, summarizes, and prioritizes emails for college students.

## Project Overview

- **Timeline:** 12 weeks (3 months)
- **Target:** 100+ beta users
- **Goal:** Build and launch MVP

## Tech Stack

- **Frontend:** Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend:** Supabase, Prisma, tRPC
- **AI:** OpenAI GPT-4, Pinecone, LangChain
- **Auth:** Clerk
- **Email:** Nylas API

## Development Status

Currently in Week 0: Pre-Development Phase

## Getting Started

1. Clone the repository
2. Install dependencies: `pnpm install`
3. Set up environment variables
4. Run development server: `pnpm dev`
